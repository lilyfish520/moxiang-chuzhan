## 如何更新

### 发布流程

```bash
cd "/Users/lily52u/Documents/Codex/墨香初绽"
git add -A
git commit -m "描述改动"
git push
```

推送后 GitHub Pages 自动部署，约 1 分钟生效。

### 新增文章

在 `index.html` 的 `const E = [...]` 数组中追加新条目：

```js
{id:12, title:"文章标题", author:"作者名", tags:["同窗好友"],
 featured:false, quote:"一句精彩引语",
 img:"images/12.jpg",
 content:["段落1","段落2","段落3"]}
```

### 新增期号

1. 复制 `index.html` 为 `issue-02.html`
2. 修改 `E` 数组为第二期文章数据
3. 更新封面文字和期号
4. 在导航栏增加第二期入口

### 更换插画

将新图片放入 `images/` 目录，命名保持 `01.jpg` ~ `11.jpg`（或按文章编号），推送即可。
